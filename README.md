# Student Management System

A simple Java console application for managing student records. It provides a menu to add, view, update, and delete students.

## Features

- Add student records
- View all students
- Update student details
- Delete student records
- Assign each student a unique ID
- Validate IDs and marks (0–100)

## Student Details

Each record includes:

- Student ID
- Name
- Course
- Marks

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections Framework

## Requirements

- Java Development Kit (JDK) installed
- A terminal or Java IDE, such as VS Code, IntelliJ IDEA, or Eclipse

## Run the Program

1. Download or clone this repository.
2. Open a terminal in the folder containing `StudentManagement.java`.
3. Compile the program:

   ```bash
   javac StudentManagement.java
